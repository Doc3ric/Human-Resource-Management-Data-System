MODULE 6 — TWG SCORING, AGENDA PREP, MASKING
6.1 Right panel reads dynamically from existing twg_rating_criteria (criterion_id, criterion_name, criterion_category, score_basis_description, point_value, thresholds); never hardcode points. Create/reference twg_scores (score_id PK; applicant_id; vacancy_id; criterion_id FK→twg_rating_criteria; auto_populated_value DECIMAL(5,2); assessor_value DECIMAL(5,2); is_edited BOOLEAN DEFAULT FALSE; assessor_notes TEXT; assessed_by; assessed_at TIMESTAMP ON UPDATE CURRENT_TIMESTAMP).
6.2 Auto-scoring on selection: Education→tier thresholds; Eligibility→vacancy bounds; Training→hour brackets (e.g., 0–24=X, 25–72=Y); Awards/IPCR/Tenure→matrix scales; Demerit→configured deduction or zero. Initialize assessor_value=auto_populated_value, is_edited=false.
6.3 Scoring sheet: columns Criterion Name, Maximum Points, Basis/Description, Auto-Populated Score (gray), Assessor Score (numeric input min=0 max=[maximum_points]), Notes. On exceedance: block submit, border var(--color-danger), warning "Exceeds maximum allowable score of [N] points for this criterion". On deviation: is_edited=true, mark with pencil icon or var(--color-accent) left border. Footer totals: Total Auto-Populated, Total Assessor, difference + edited-count badge. Final card: cumulative, percentage, adjectival classification.
6.4 Controls & gate: Overall Assessment Notes; Assessor Recommendation (Highly Recommended/Recommended/Recommended with Reservation/Not Recommended); mandatory certification checkbox "I certify that this evaluation was conducted in accordance with the approved TWG Rating Criteria and the 2025 ORAOHRA Rule IX, and that all scores are based on submitted and verified documents." Submit disabled until checkbox checked AND no out-of-range value AND photo attached. On submit: save, status Submitted, lock form; only an HRMPSB Chairperson unlocks (logged). Evaluation History: expandable read-only timeline (user, action, timestamp, total score).
6.5 Agenda prep: "Generate Agenda" restricted to WHERE is_qualified=true; multi-select offices/items. Part I Preliminary Editor (rich-text/Markdown) + free-text dynamic insertion before Part II. Part II Deliberation Matrix (non-editable): Selected Offices → Active Vacancies → Qualified Applicants (tagged Job Order/External/Exempted), with "Action Taken / Board Resolution" input per candidate.
6.6 Blind scoring ID: on entering deliberation, re-code identifier as birthdate(DDMMYY)+"&"+item number (e.g., 150878&0024). Scoring tables use this, never raw names.
6.7 CER selector: position_level==1 → Level_1_CER_Format.rpt; ==2 → Level_2_CER_Format.rpt. No manual choice.
