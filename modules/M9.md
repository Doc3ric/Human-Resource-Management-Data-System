```
MODULE 9 — IDCC: INTELLIGENT DOCUMENT CAPTURE & CLASSIFICATION
Standalone intranet Flask Blueprint (/idcc), on-premise, no external API calls. 8 stages:
1 Universal Ingestion: accept PDF/JPG/PNG/TIFF/DOCX/XLSX/TXT (single or batch); SHA-256 per payload; never drop — unreadable → manual-review queue.
2 OCR: on-premise Tesseract; text → LONGTEXT with MySQL FULLTEXT index; low ocr_confidence → flag for human validation.
3 Classification: doc_type_code (APPT-33A, PDS-212, LEAVE-CSC6, DISC-RACCS, LGU-EO, COE-REQ…); importance_class (Vital/Important/Useful/Routine); privacy_tier (1 Restricted/2 Protected/3 Internal); abstract_description (2–3 sentences).
4 Data-Privacy Triage (R.A. 10173 + NPC): regex/keyword-detect SPI (GSIS BP, PhilHealth, TIN, SSS, addresses, SALN/financial, medical, blood type); on match AES-256 encrypt at rest, set privacy_tier=1, build masked redacted version for standard users; full files restricted; every access → tbl_spi_access_log.
5 RACCS Confidentiality Wall (CSC Res. 2500357): DISC-RACCS docs isolated to an air-gapped directory; EXCLUDED from the global FULLTEXT index, mapped to a separate access-gated index; AES-256 at rest; MFA restricted to Disciplining Authority/Legal Officers/active CODI; all attempts logged to an air-gapped security log.
6 Relationship Mapping: tbl_doc_relations (e.g., Transcript SUPPORTING_ELIGIBILITY to an appointment; medical cert to a CSC Form 6); link via names/indexes to personnel_id.
7 Auto-Foldering: partition by doc_type_code + privacy_tier + importance_class; confidential/SPI inherit Stage 4–5 restrictions; standard users cannot hard-delete.
8 Retention (R.A. 9470 + NAP RDS): Appointments (33-A/B) & core 201 = Permanent; PDS (212) = active tenure then post-separation review; disciplinary = permanent if dismissal/major penalty else long-term cap; CSC Form 6 leave = per accounting/audit, disposal only after a verified consolidated ledger, always audited.
```
